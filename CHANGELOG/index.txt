<h2>v6.0.1 (2023-06-08)</h2>
<p>This version has been in the works for a few years. It includes several new features that were highly requested, numerous bug fixes, new documentation, and aggresively encourages migrating from the old Google Universal Analytics to the new Analytics 4.</p>
<h4>Breaking changes</h4>
<ul>
<li>As of July 2023, Google Universal Analytics is going away and being replaced by Google Analytics 4. Beautiful Jekyll sites that still use the old analytics tag will show a warning to encourage them to move to Analytics 4 (#1096).</li>
<li>More control over RSS feed sharing: previously, an RSS feed was <em>always</em> generated, and if the config setting <code>rss-description</code> was set then there was an RSS icon in the footer. Now, an RSS feed is only generated when the config setting <code>rss-description</code> exists, and an RSS footer icon is only shown if <code>rss: true</code> is set in the <code>social-network-links</code> config settings.</li>
</ul>
<h4>New parameters and settings</h4>
<ul>
<li>Added <code>navbar-var-length</code> config setting that allows the navigation menu to be the same length as the longest sub-menu, so that long words in the submenu are not cut off (#765)</li>
<li>Added <code>post_search</code> config setting that creates a Search button in the navbar (#770)</li>
<li>Added <code>edit_page_button</code> config setting that adds a "Edit page" button to the footer (to edit the current page on GitHub) (#1004)</li>
<li>Added <code>footer-hover-col</code> config setting to customize the hover colour of links in the footer (#848)</li>
</ul>
<h4>New features and improvements</h4>
<ul>
<li>Made the home page feed more accessible for screen readers (#950)</li>
<li>Added support for giscus comments (#886) and CommentBox (#960)</li>
<li>Added support for Cloudflare Analytics (#797)</li>
<li>Added Reddit in share options of posts (#815)</li>
</ul>
<h4>Bug fixes</h4>
<ul>
<li>Fixed page titles, subtitles, and excerpts rendering correctly when there are special characeters in them (#856)</li>
<li>Fixed bug where navbar secondary level dropdown items didn't inherit the same colour as the primary navbar links</li>
<li>Fixed bug where the navbar "burger" collapsed button didn't always revert back to a light colour</li>
<li>Fixed bug where using an image as a navbar title did not render in GitHub Project pages that did not have a custom domain</li>
<li>Fixed bug where image thumbnails on the feed page were always forced into a square rather than maintaining a proper image aspect ratio</li>
<li>Fixed bug where special characters in the title led to broken share tags (#744)</li>
<li>Fixed bug where staticman didn't work jQuery slim version is used (#766)</li>
<li>Fixed very long strings to wrap around the next line rather than go off-screen (#787)</li>
</ul>
<h4>Small changes</h4>
<ul>
<li>Updated staticman from using v2 (public servers) to v3 (private servers) due to the public servers becoming obsolete (#775)</li>
<li>Added social network links for Patreon, Medium, Itch.io, Discord, Kaggle, Hackerrank (#783, #788, #907, #961, #978)</li>
<li>Slightly reworked margins and position for avatar image to resolve an alignment issue on Safari</li>
<li>Changed the width at which the navbar collapses to a higher threshold because most modern non-mobile browsers are >1000px</li>
</ul>
<h2>v5.0.0 (2020-09-15)</h2>
<p>One of the major changes in this version is that a lot of time was spent on rethinking the entire SEO and social media sharing model (how a page looks on eg. Google, Twitter, Facebok). It was redesigned to be more simple and customizable. The new documentation has a section dedicated to SEO and social media sharing of a page. Unfortunately some changes that are not backwards-compatible had to be made.</p>
<h4>Breaking changes</h4>
<ul>
<li>Renamed <code>description</code> YAML parameter to <code>share-description</code> to be more clear</li>
<li>Renamed <code>description</code> config setting to <code>rss-description</code> since it was only used in RSS (the FAQ explains the difference between YAML parameters and config settings if you're confused)</li>
<li>Removed YAML parameter <code>use-site-title</code> (you can now specify the exact title using <code>share-title</code>)</li>
<li>Removed undocumented YAML parameters <code>meta-title</code> and <code>meta-description</code></li>
<li>Removed <code>link-tags</code> config setting because it wasn't necessary. If you use tags, there will now always be a tags page created; if you don't use tags there won't be a tags page.</li>
<li>The YAML parameter <code>show-avatar</code> is now true by default. This has always been the case for GitHub Pages users, but not for <code>remote_theme</code> users. For consistency, it's now the default for everyone. (#715)</li>
</ul>
<h4>New parameters and settings</h4>
<ul>
<li>Added <code>full-width</code> YAML parameter to allow having full-width pages</li>
<li>Added <code>feed_show_excerpt</code> config setting to show/hide the post excerpts on the feed page</li>
<li>Added <code>feed_show_tags</code> config setting to show/hide the list of tags on post previews on the feed page</li>
<li>Added <code>share-title</code> YAML parameter to give control over the search engine/social media title</li>
<li>Added <code>last-updated</code> YAML parameter to show a "Last Updated on" date for blog posts</li>
<li>Added <code>before-content</code> and <code>after-content</code> YAML parameters that allow you to add some common HTML before the main content of a page (below the title) or after the main content (above the footer). Works in a similar way to <code>footer-extra</code>.</li>
<li>Added <code>head-extra</code> YAML parameter which is similar to <code>footer-extra</code> but is used to include custom HTML code in a page's <code>&#x3C;head></code> tag</li>
<li>Added <code>site-js</code> config setting to provide JavaScript files that are used on all pages in the site</li>
</ul>
<h4>New features and improvements</h4>
<ul>
<li>Improved the <code>footer-extra</code> YAML parameter to support multiple files instead of only a single file</li>
<li>Added automatic navbar color detection (#702)</li>
<li>When <code>nav-short</code> is turned on, the avatar will also be shorter</li>
<li>Changed navbar and footer background colour to be slightly darker, for better contrast with the default white page background for accessibility reasons</li>
<li>Changed the behaviour of <code>site-css</code> to include site-wide CSS file <strong>before</strong> instead of after page-specific files</li>
<li>Renamed internal css/js files from "main" to "beautifuljekyll" to make it easier for users to troubleshoot</li>
<li>Added alt text to all images for better accessibility</li>
<li>Made thumbnail images square instead of circles, as users reported that circles cut off important parts of images</li>
</ul>
<h4>Bug fixes</h4>
<ul>
<li>Fixed rendering issues with <code>nav-short</code> parameter that caused the body of the page to start too low</li>
<li>Fixed some CSS styles that broke during the bootstrap 4 migration (#716)</li>
</ul>
<h4>Library upgrades</h4>
<ul>
<li>Upgraded kramdown to version 2.3.0 to fix security issues</li>
<li>Upgraded jQuery to version 3.5.1 to fix a couple security vulnerabilities with the previous version</li>
</ul>
